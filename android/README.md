# FreeRDPTun для Android

Нативный тестовый клиент (Kotlin, Jetpack Compose). Весь IPv4-трафик устройства уходит в VPN-интерфейс (`0.0.0.0/0`),
затем через Go-ядро (`mobile/core`) и встроенный FreeRDP (DVC) на сервер.

Функции: добавление конфигурации из JSON (QR позже), редактирование всех полей, удаление, выбор конфигурации по
умолчанию, кнопка Подключиться/Отключиться, журнал.

## Запуск
1. Откройте папку `android` в Android Studio (JDK 17, Android SDK 36). Готовые `.so` для arm64-v8a уже лежат в
   `app/src/main/jniLibs/arm64-v8a`.
2. Подключите устройство (Android 8+, arm64; эмулятор x86 не поддерживается) и нажмите Run.
3. При первом подключении Android покажет системный запрос VPN.

## Пересборка нативных библиотек
```
export ANDROID_NDK_HOME=$HOME/Library/Android/sdk/ndk/<версия>   # или Linux-путь
android/scripts/build-android-libs.sh
```
Нужны NDK r27+, Go 1.23+, cmake, ninja, perl, curl; исходники FreeRDP в `third_party/FreeRDP`
(как в сборке iOS). Библиотеки собираются с выравниванием 16 КБ (требование Android 15+).

## Замечания
- Приложение исключено из VPN (`addDisallowedApplication`), поэтому сокет FreeRDP идёт напрямую.
- Туннель только IPv4; IPv6 перехватывается и отбрасывается (опция «Блокировать IPv6»).
- Профили хранятся в SharedPreferences без шифрования, автопереподключения нет.
- Сервер должен выполнять NAT и маршрутизацию для адреса из `cidr`.
