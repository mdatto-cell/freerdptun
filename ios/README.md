# FreeRDPTun для iOS (тестовый клиент)

Нативное SwiftUI-приложение + расширение Packet Tunnel (NetworkExtension).
Весь IPv4-трафик iPhone (маршрут по умолчанию) отправляется в туннель.
Работает только на реальном устройстве: Packet Tunnel не запускается в симуляторе.

## Как устроено

```
iOS  ──packetFlow──▶ PacketTunnelProvider.swift
                          │  FRTPushPacket / FRTPopPacket
                     libfrtcore.a (Go, ios/core)  ← неизменённая логика internal/tunnel
                          │  два pipe (тот же формат кадров, что stdin/stdout)
                     libfrtbridge.a (native/bridge.c, -DFRT_LIBRARY) + статический FreeRDP 3.28.0
                          │
                     TCP/TLS ─▶ сервер FreeRDPTun
```

На iOS нельзя запускать дочерние процессы, поэтому `rdpt-bridge` собирается как библиотека и
работает потоком внутри расширения. Протокол, аутентификация по UUID, pin сертификата и
транспортная политика — те же, что в Linux/Windows-клиентах. Серверные части в iOS-сборку не входят.

## Сборка (macOS, Xcode)

```bash
brew install cmake ninja go xcodegen perl
# 1. нативные библиотеки (OpenSSL, FreeRDP, bridge, Go-ядро) -> ios/Libs
bash ios/scripts/build-ios-libs.sh
# 2. отредактируйте ios/project.yml: BUNDLE_ID_PREFIX и DEVELOPMENT_TEAM
cd ios && xcodegen generate && open FreeRDPTunIOS.xcodeproj
```

В Xcode выберите схему `FreeRDPTun`, свой iPhone, нажмите Run. Автоматическая подпись
создаст профили с возможностью Network Extensions (Packet Tunnel) для приложения
и расширения (`<prefix>.freerdptun` и `<prefix>.freerdptun.tunnel`). При первом запуске iOS
спросит разрешение на добавление VPN-конфигурации.

## Использование

- `+` — добавить конфигурацию: вставьте JSON клиента (поле названия необязательно).
  Неизвестные поля и серверные настройки отклоняются так же, как в Go-клиенте.
- Нажатие на конфигурацию — редактирование всех полей по отдельности; внизу виден итоговый JSON.
- Свайп вправо — «По умолчанию» (звезда), свайп влево — удалить.
- Кнопка «Подключиться / Отключиться» работает с конфигурацией по умолчанию.
- Иконка документа слева — журнал расширения (Go и FreeRDP), доступен во время подключения.

Параметры приложения вне JSON (на конфигурацию): DNS-серверы (по умолчанию 1.1.1.1, 8.8.8.8;
запросы уходят в туннель) и блокировка IPv6. Туннель только IPv4, поэтому при включённой блокировке
IPv6-пакеты захватываются и отбрасываются, чтобы не обходить туннель.

## Требования к серверу

Автоматической маршрутизации нет: на сервере должны быть включены forwarding и NAT для
подсети туннеля (например, `10.77.0.0/24`), иначе страницы не откроются.
MTU в конфигурации должен совпадать с серверным (клиент проверяет это при авторизации).

## Ограничения

- Конфигурации (включая UUID) лежат в UserDefaults приложения и в настройках VPN: для тестов
  достаточно, для релиза нужно перенести в Keychain.
- Автопереподключения нет; при обрыве туннель завершается, причина показывается на главном экране.
- Лимит памяти расширения около 50 МБ: Go ограничен `SetMemoryLimit(28 МБ)`.
